# S02 WN21 kalici output kesinti kaydi - customer gate kapali

- `InventoryRepository.writeTestRunProvenance` mevcut `test_run_provenance` ve `artifacts` tablolarini kullaniyor; S04 migration eklenmedi. Baseline, candidate ve final replay dispatcher yollari `RunResult` ham/rendered kesinti sayaclarini ve sebebini iletiyor.
- Kesinti varsa `ArtifactStore` once run id/job id/stage/sayac/sebep iceren schema v1 JSON blob'u content-addressed yayimliyor. Ardindan run provenance ve `run_output_truncation` artifact satiri tek SQLite transaction'da yaziliyor. `pin_reason=run_output_truncation:<run_id>` GC'nin bu kaniti silmesini engelliyor. Ayni run tekrarinda ayni hash kabul edilir; degismis hash veya READY olmayan artifact fail-closed. Onceden kesinti kaniti olmayan eski run'a yeni artifact sonradan eklenemez.
- Gercek SQLite/ArtifactStore fixture'i 1) run+artifact kaydini ve byte icerigini, 2) ayni run idempotence/degismis sayac reddini, 3) artifact INSERT trigger hatasinda run satirinin rollback'ini, 4) blob yayimlandiktan sonraki FK hatasinda iki DB satirinin de olusmadigini, 5) eski run'a kanit backfill reddini dogruladi. `wn-run-truncation-provenance` + `fin03-relations` seri 2 dosya/15 PASS; onceki `p05b-resume` + `wn-native-entrypoint` + yeni fixture seri 3 dosya/23 PASS.
- Yayim ile DB transaction arasindaki hard-kill, kayitsiz content-addressed blob birakabilir. Mevcut `retention-gc` yalniz `artifacts` satirlarini tarar; bu fiziksel orphan blob'u su an otomatik toplamaz. Blob hicbir READY satirina baglanmadigindan trusted kanit sayilmaz; orphan sweep ayri S01/storage kabuludur. Disk birikimi acik operasyonel risktir.
- Envanter yazma noktasina ulasmayan Maven hatalari icin bu artifact uretilmez; tum stdout/stderr streamlerinin evrensel durable provenance kaniti degildir. WN21 yazili log 8 MiB siniri kanitli, fakat WN22/23 bagimsiz reaper ve WN14/15/18 toolchain kapilari dahil S02/customer readiness ile G1/G2/G3 NO_GO kalir.
- Bagimsiz review P2 coklu pin duzeltmesi: schema `(job_id,kind,pin_reason)` tekilligi zorlamadigindan ayni run pin'i altina ikinci READY artifact eklenebiliyordu. RED fixture tekrarinda `.get()` ilk satiri okuyup celiskiyi kabul etti; GREEN preflight ve SQLite transaction icinde tum eslesen satirlari sayip `>1` icin `STORAGE_ERROR` fail-closed. Gercek SQLite fixture 5/5 PASS. Schema migration eklenmedi.
